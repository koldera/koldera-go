# koldera-go

Go SDK for [koldera-core](https://github.com/koldera/koldera-core): PDF/UA checks and fixes, HTML and structured
documents to tagged PDF, web scans. Module `github.com/koldera/koldera-go`, package `koldera`, standard library only.

Status: early release (0.1), targeting the koldera-core API 0.1. Documentation will follow with the first release; see
the package documentation and the examples in `example_test.go`.
